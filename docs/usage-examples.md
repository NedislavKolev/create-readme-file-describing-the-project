# Usage Examples

## Example 1: Running the Main Script
Run the main application:
```
python src/main.py
```
This command will execute the primary code in the `main.py` file.

## Example 2: Using the Application Features
You can access various features of the application directly from the command line after running the main script. Please refer to the documentation for detailed feature descriptions.

## Example 3: Feature with Arguments
You can run the main script with arguments like this:
```
python src/main.py --option your_argument
```
This will allow you to customize the execution based on the given arguments.
